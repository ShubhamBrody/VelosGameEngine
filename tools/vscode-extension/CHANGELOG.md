# Changelog

## 0.1.0 - 2026-09-07

- Stable VS Code MCP provider for the native Velos editor, with 60 bundled tools and nine resources.
- Workspace-specific connections, explicit start/attach commands, status/output and read-only mode.
- Workspace trust and local-Windows restrictions; configuration fingerprints prevent stale permission reuse.
- Official SDK bundled into the VSIX with dependency notices; no runtime npm installation required.
- Unit and real VS Code extension-host tests, including native scene authoring and read-only rejection.
